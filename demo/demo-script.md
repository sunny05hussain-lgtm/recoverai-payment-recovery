# 5-minute demo script - draft

1. **0:00-0:30:** Explain the revenue-recovery problem.
2. **0:30-1:00:** Show the dashboard and headline metrics.
3. **1:00-2:30:** Open one failed payment and run the recovery workflow.
4. **2:30-3:30:** Show a case refused because of fraud suspicion, high value, or retry limits.
5. **3:30-4:15:** Show held-out evaluation metrics.
6. **4:15-4:45:** Show the architecture and audit log.
7. **4:45-5:00:** Explain the product value and limitations.
